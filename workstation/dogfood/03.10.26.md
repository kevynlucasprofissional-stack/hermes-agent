- Vi um repositório que transforma páginas web em APIs e pensei em nos inspirarmos nisso para o Hermes Work. A ideia seria transformar o próprio Google AI Studio em uma API: em vez de gastar com uma chave de API paga para transcrição de áudio, poderíamos usar o Gemini direto pela interface do AI Studio. Assim, sempre que um áudio for recebido, o Hermes Work o envia para lá e recebe a transcrição, economizando créditos. Se conseguirmos converter páginas em endpoints de API, podemos aplicar essa mesma lógica em várias outras frentes.
