Temos que verificar a integração do Hermes Work com o Hermes Upstream, depois da sincronização com o estado atual do upstram o Hermes Work não está funcionando como deveria.
O ideal deve ser fazer seamns mais profundos no código fonte do Hermes Upstream, se não for assim o Hermes Work não funciona direito, mas, devemos trabalhar de uma forma que o core seja bem definido e funcione por si só e que os seams, ou seja, as modificações no código fonte do upstream sejam apenas para fazer com que a integração funcione de forma mais robusta, precisa e segura. E aí criamos um arquivo que mostre onde todas as costuras no código fonte foram feitas, e por qual motivo. Precisamos usarmos essa costura com bastante inteligência e encontrar um ponto ótimo, um equilibrio na quantidade de costuras. A quantidade de costuras no código fonte deve ser ideal para que o Hermes Work e o Hermes Agent (Upstream) funcionem em uma simbiose perfeita, como se fossem um só produto, mas que não sejam exagerados, pois se forem muitos, se forem costuras de mais pode acontecer do upstream mudar a arquitetura dele e o trabalho para adaptar o Hermes Work a nova arquitetura será gigantesco.
Dito isto, o próximo passo agora é procurar as funcionalidades do Hermes Work que funcionariam melhor se houvessem costuras diretas com o código fonte do Hermes Agente (Upstream), eu sei que as funcionalidades do Browser que criamos, e do experience_compiler atualmente não estão funcionando direito, e requerem costuras mais profundas e de mais qualidade no código fonte do upstream.
