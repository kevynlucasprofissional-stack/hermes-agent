Penalize unqualified prerequisites Q (0–5). Preliminary ranking: `(N+C+V+P+E) - 2Q`. Do not turn this heuristic into an objective benchmark; revise against cheap-model experiments. Candidates without an independently falsifiable outcome are rejected until better scoped.

## Delegate to cheaper tools by default
- CI `workstation-laya` extra (#54), reproducing logs, writing status docs, trivial type fixes, deterministic file inventories, smoke tests, import indexing, package audit inventories, low-risk refactors, test fixture boilerplate.
- Full repository and external-source reading/triage; no reason to pay a frontier model for navigation.
- Cargo-cult task multiplication, untested adapters, UI placeholder screens and empty stubs are NOT acceptable outcomes.

## Preferred cross-cutting slice (evidence-gated)
**Not "implement every roadmap entry superficially".** Instead:
1. Restore qualified baseline and trustworthy real effect verification (cheap baseline repairs + frontier only for genuine semantic architecture conflicts).
2. Establish minimal, reusable, typed `CreativeProjectManifest`, capability discovery/authority/revision/evidence contract using existing owners.
3. Prove **one complete** creative path (CW-03A) in native Electron with editable source, real PNG and negative controls; then FFmpeg and independent Penpot/Three.js families.
4. Allow Experience Compiler to observe verified creative outcomes and safely reuse them via D-038/D-039 boundaries after a vertical passes.
This yields a real foundation shared across roadmap items instead of a large set of shallow demos.

## Promotion rule
A candidate gets a paid packet only when:
- Evidence shows a **known missing behavior** (not just a roadmap idea), exact owner signatures and concrete test.
- Proves cheaper model struggles on a well-scoped task or premium reasoning gain is otherwise defensible.
- New code can pass independent negative and integration tests, and roll back cleanly.
- Task does not require bypassing H-079, safety, privacy or license restrictions.
- Scope fits a small code-changing branch/PR, not an entire fork refactor in one response.

**Do not submit this shortlist verbatim to Anthropic.** Each promoted candidate must become a frozen, self-contained code packet.
