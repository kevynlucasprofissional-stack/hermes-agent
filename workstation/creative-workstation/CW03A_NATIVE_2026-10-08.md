The existing WorkstationBrowserRuntime accepts a typed `browser_creative_render`
operation for an already-bound BrowserTask, matching session/run and explicit
operation identity. It rejects a changed owner before rebinding and rechecks
human control/owner throughout export. Shapes and text become SVG in a script-
and network-blocked document; there is no arbitrary JavaScript input. Geometry,
zoom and foreground tab are preserved. The existing native parking lifecycle
hosts background views; no second browser, server or process manager is created.

The editable source is a versioned canvas JSON document, and the output includes
native SVG plus PNG hashes and BrowserOwnerReceipt. Rectangles, circles and text
are supported by this first static adapter; it is not a general graphics editor.
